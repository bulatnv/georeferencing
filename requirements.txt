# Ядро: то, без чего пакет не импортируется (NumPy + OpenCV).
#
#     pip install -r requirements.txt
#
# Ставит и сам пакет в editable-режиме — `scripts/` и примеры рассчитывают на то,
# что `aero_geoloc` импортируется из любого каталога.
#
# Наборы под задачи (каждый включает этот):
#
#   requirements-dev.txt    тесты и синтетический стенд        (+ pytest)
#   requirements-real.txt   боевой конвейер на реальных кадрах (+ torch, LightGlue, FAISS)
#   requirements-lock.txt   точные версии проверенного окружения (воспроизводимость)
#
# Источник истины по версиям — `pyproject.toml`; здесь только точка входа. Заодно
# она обходит поломку квадратных скобок в PowerShell: `pip install -e '.[dev]'`
# оттуда не работает, а `pip install -r ...` работает везде одинаково.
#
# OpenCV нужен именно в сборке contrib: в OpenCV 5 детектор AKAZE переехал в
# `cv2.xfeatures2d` (шим — в `aero_geoloc/matcher.py`).
# Тайлы подложки качаются через stdlib, отдельной зависимости не требуют.

-e .
